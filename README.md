# 🏡 Real Estate Management System

A full-stack real estate application that allows users to explore property listings and manage properties with role-based access control.

## 🚀 Features

- **Authentication:** Secure login and registration using JWT.
- **Role-Based Access:** Separate permissions for Admin, Owner, and Buyer.
- **Property Management:** Create, view, and manage property listings.
- **Admin Dashboard:** Manage properties and update their status.
- **Database Integration:** MongoDB with Mongoose.

## 🛠️ Tech Stack

- **Backend:** NestJS
- **Frontend:** React
- **Database:** MongoDB
- **Authentication:** JWT

## ⚙️ Installation

```bash
git clone https://github.com/bhardwaj0052/real-estate-.git
cd real-estate-
npm install
npm run start:dev
```

Configure your MongoDB connection and JWT secret in the `.env` file before running the application.

## 👥 User Roles

- **Admin:** Manage property listings and their status.
- **Owner:** Add and manage properties.
- **Buyer:** Browse available properties.
