# 🏡 Real Estate Management System

A full-stack real estate application with role-based access for Admin, Owner, and Buyer.

## 🚀 Features

- JWT Authentication
- Role-Based Access Control
- Property Listing and Management
- Admin Property Status Management
- MongoDB Integration
- Swagger API Documentation

## 🛠️ Tech Stack

- **Frontend:** React
- **Backend:** NestJS, Node.js
- **Database:** MongoDB
- **Authentication:** JWT, Passport.js

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/bhardwaj0052/real-estate-.git
cd real-estate-
```

### 2. Start the Backend

```bash
cd backend
npm install
npm run start:dev
```

### 3. Start the Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

## 👥 User Roles

- **Admin:** Manage properties and update their status.
- **Owner:** Add and manage properties.
- **Buyer:** Browse available properties.

## 🔐 Environment Variables

Configure the required MongoDB connection URL, JWT secret, and other environment variables in the backend `.env` file.
